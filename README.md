# ATM Simulator 🏦
A Python-based banking interface demonstrating persistent state management and user authentication.

### 🚀 Features
- **User Authentication**: Secure login using dictionary-based PIN verification.
- **Persistent Balance**: Real-time balance updates using augmented assignment.
- **Input Sanitization**: Handles user input errors gracefully using `.strip()` and `.title()`.

### 💻 Sample Usage
- **Input**: Name: `Daniel`, PIN: `1111`, Withdraw: `500`
- **Output**: `Success! Collect your 500. Remaining balance: 9500`
